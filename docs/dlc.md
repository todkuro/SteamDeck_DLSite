# DLC とパッチ

## DLC を本編に重ねる

DLsite の API には **DLC を示す情報も、本編への参照も無い**。購入済みの作品を
全数調べたところ `work_type` も `purchase_type` も本編と DLC で同じ値だった。
そのため自動判別はせず、関係は利用者が宣言する。

重ね方は作品によって違う。ライブラリにあった 3 例:

| 組 | 操作 | 起動する exe |
|---|---|---|
| 本編 ← 大型パッチ | DLC 全体を本編の直下へ（168 個上書き） | 本編側 |
| 本編 ← 追加 DLC | DLC 全体を本編の直下へ（8 個上書き。exe も差し替わる） | 本編側 |
| 本編 ← 続編（完全版） | **本編の** `<章>/Content` を **続編の** `Content` へ | **続編側** |

3 例目は方向が逆で、本編の一部フォルダだけが対象になる。この違いを吸収するため、
関係は「**どの作品のどのパスを、どの作品のどのパスへ**」の 4 項目で持つ。

ライブラリの行の **DLC** ボタンから設定する。指定する項目は 4 つ:

| 項目 | 内容 |
|---|---|
| **相手の作品** | 既定で**同じ出品者の導入済み作品**に絞られる（上の 3 組はいずれも出品者 ID が一致した）。「別の出品者も表示する」で解除できる |
| **重ね方** | 「この作品を、相手に重ねる」（多くの DLC・パッチ）か、「相手の中身を、この作品に取り込む」（続編側で起動する形）。これがコピーの向きを決める |
| **コピー元 / コピー先のフォルダ** | 空欄なら全体・直下。「選ぶ」を押すと作品の中を辿って指定できる |
| **置き方** | コピー（既定）か、**シンボリックリンク**（容量を節約する。本編を消すとリンクが切れる点に注意） |

適用前に必ず「下見する」で**上書きされるファイル数**が出る。上書きされる分は
`.dlsite_backup/<作品ID>-<印>/` に退避してから置き換える。

## 取り消す

**DLC** ダイアログの上に、その作品が絡む結び付けが並ぶ。行ごとに 2 つ選べる:

| 操作 | すること |
|---|---|
| **書き戻す** | 退避しておいた元のファイルを戻す。DLC が**新しく追加した**ファイルは残る（退避の中身だけではどれが DLC 由来か区別できないため） |
| **記録を外す** | 結び付けの記録だけ消す。**重ねたファイルはそのまま**残る |

退避は**結び付けごとに 1 つ**で、中身は常に手つかずの原本。同じ結び付けを何度
重ね直しても増えず、いつ書き戻しても重ねる前の姿に戻る。作品を削除すると、
その作品を名指しした退避も一緒に片付ける。

### 注意

- 本編を再取得すると DLC は消える。重ね直しが要る。
- 「適用済み版」「完全版」のような**単体で完結した版**も存在する。
  重ねる前に下見でファイルの重なりを確認すること。

## exe を実行して当てるパッチ

`patch.exe` を実行して適用するパッチもある。Steam に登録した
非 Steam ゲームにも Proton プレフィックスが作られるので、そこで実行できる。
ライブラリの行の **パッチ** ボタンから、exe を 1 つずつ選んで実行する。

**「当てる先のゲーム」を選ぶ**のが要点。パッチは別の作品として購入するため、exe を
持っている作品と、当てる相手のゲームは別物になる。選べるのは **Steam に登録して
一度起動したゲームだけ**（プレフィックスがまだ無いものには当てられないため）。

1 つの作品に複数の exe が入っていることがある（実物のパッチ特典セットで 12 個）。フォルダ名まで含めた相対パスで表示するので、どのキャラの
どのパッチかを見て個別に選べる。実行済みのものには印が付く。

**そのゲームに割り当てられている Proton が自動で選ばれる。** ここは手作業だと
最も間違えやすい部分で、違う版で実行するとプレフィックスが変換され、
**元に戻せない**。実機では `proton_experimental` / `GE-Proton10-10` /
`Proton-GE Latest` / `proton_hotfix` / `proton_7` などが混在していた。

プレフィックスは **Steam に登録して一度起動する**と作られる。まだ起動していない
ゲームには当てられないので、先に一度起動しておくこと。

手作業で行う場合は次の通り（`<AppID>` は符号なし）:

```bash
export STEAM_COMPAT_CLIENT_INSTALL_PATH="$HOME/.steam/steam"
export STEAM_COMPAT_DATA_PATH="$HOME/.steam/steam/steamapps/compatdata/<AppID>"
cd "<ゲームのフォルダ>"
"$HOME/.steam/steam/steamapps/common/Proton - Experimental/proton" run ./patch.exe
```
