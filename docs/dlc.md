# DLC とパッチ

## DLC を本編に重ねる

DLsite の API には、ある作品が DLC かどうかや、どの本編の DLC なのかを示す情報がありません。
本編と DLC で作品の種類を表す値も同じなので、ツールが自動で判別することはできません。
そのため、どの作品をどの作品に重ねるかは、利用する人が指定します。

重ね方は作品によって異なります。作者のライブラリにあった例を 3 つ挙げます。

| 組み合わせ | 重ね方 | 起動する exe |
|---|---|---|
| 本編 ← 大型パッチ | DLC の中身をすべて本編のディレクトリへコピー（168 ファイルを上書き） | 本編 |
| 本編 ← 追加 DLC | DLC の中身をすべて本編のディレクトリへコピー（8 ファイルを上書き。exe も置き換わる） | 本編 |
| 本編 ← 続編（完全版） | 本編の `<章>/Content` を、続編の `Content` へコピー | 続編 |

3 つ目の例は、コピーする向きが逆で、しかも本編の一部のディレクトリだけが対象です。
このような違いに対応できるように、「どの作品のどのディレクトリを、どの作品のどのディレクトリへコピーするか」を指定する形にしています。

### 重ね方

ライブラリの各行にある「DLC」ボタンから設定します。指定する項目は次の 4 つです。

| 項目 | 内容 |
|---|---|
| 相手の作品 | 最初は、同じサークル（出品者）の導入済み作品だけが表示されます。「別の出品者も表示する」にチェックを入れると、すべての作品から選べます |
| 重ね方 | 「この作品を、相手に重ねる」（多くの DLC やパッチ）か、「相手の中身を、この作品に取り込む」（続編の側で起動する場合）から選びます。これでコピーの向きが決まります |
| コピー元・コピー先のディレクトリ | 空欄にすると、作品のディレクトリ全体（コピー先はディレクトリの直下）が対象になります。「選ぶ」を押すと、作品の中のディレクトリをたどって指定できます |
| 置き方 | 「コピーする」（既定）か「シンボリックリンクにする」から選びます。シンボリックリンクは容量を節約できますが、コピー元の作品を削除するとリンクが切れます |

適用する前に「下見する」を押すと、上書きされるファイルの数が表示されます。
上書きされるファイルは、`.dlsite_backup/<作品ID>-<識別子>/` に退避してから置き換えます。

### 取り消す

「DLC」ボタンで開く画面の上部に、その作品に関係する DLC の適用が「DLC適用済み状況」として一覧で表示されます。行ごとに次の操作ができます。

| 操作 | 内容 |
|---|---|
| 書き戻す | 退避しておいた元のファイルを戻します。DLC によって新しく追加されたファイルは残ります（退避したファイルだけでは、どれが DLC のファイルか判断できないためです） |
| 記録を外す | 作品間で DLC を適用したという情報だけを消します。重ねたファイルはそのまま残ります |

退避したファイルは、DLC の適用 1 件につき 1 組だけ保存します。中身は常に、重ねる前の元のファイルです。
同じ DLC を何度適用し直しても退避したファイルは増えず、いつ書き戻しても重ねる前の状態に戻ります。
作品を削除すると、その作品の退避したファイルと、作品間で DLC を適用したという情報も一緒に削除されます。
DLC 側の作品を削除しても、重ねたファイルは相手の作品に残ります。

### 注意

- 本編をダウンロードし直すと、重ねた DLC の内容は消えます。もう一度重ねてください。
- 「適用済み版」や「完全版」のように、それだけで遊べる版もあります。重ねる前に「下見する」で、ファイルの重なり具合を確認してください。

## exe を実行して当てるパッチ

`patch.exe` のような exe を実行して当てるパッチもあります。
Steam に登録したゲームには、Proton の環境（プレフィックス）がゲームごとに作られるので、その中でパッチの exe を実行できます。
ライブラリの各行にある「パッチ」ボタンから、exe を 1 つずつ選んで実行します。

大事なのは、パッチを当てる先のゲームを選ぶことです。パッチはゲームとは別の作品として購入するので、パッチの exe が入っている作品と、パッチを当てるゲームは別のものになります。
選べるのは、Steam に登録して一度起動したことのあるゲームだけです。プレフィックスは、Steam からゲームを初めて起動したときに作られるためです。まだ起動していないゲームにパッチを当てたいときは、先に一度起動してください。

1 つの作品に複数の exe が入っていることもあります（作者が購入したパッチのセットには 12 個入っていました）。
exe はディレクトリ名を含めて表示するので、どれが何のパッチかを確認しながら選べます。実行済みの exe には印が付きます。

パッチの exe は、そのゲームに割り当てられている Proton で実行します。
これは手作業ではもっとも間違えやすい部分です。違うバージョンの Proton で実行するとプレフィックスが変換されてしまい、元に戻せません。
作者の環境でも、`proton_experimental`・`GE-Proton10-10`・`Proton-GE Latest`・`proton_hotfix`・`proton_7` などがゲームごとに混在していました。

手作業で当てる場合は、次のように実行します（`<AppID>` は符号なしの数値です）。

```bash
export STEAM_COMPAT_CLIENT_INSTALL_PATH="$HOME/.steam/steam"
export STEAM_COMPAT_DATA_PATH="$HOME/.steam/steam/steamapps/compatdata/<AppID>"
cd "<ゲームのディレクトリ>"
"$HOME/.steam/steam/steamapps/common/Proton - Experimental/proton" run ./patch.exe
```

最後の行の Proton は、そのゲームに割り当てられているものに置き換えてください。
