# コマンドライン

Web UI でできることは、ほとんど端末からも実行できます。自動化したいときや、Web UI を使えないときに利用してください。
ただし、DLC の重ね合わせ、パッチの実行、作品の削除は Web UI でしかできません（[DLC とパッチ](dlc.md)）。

## コマンドの一覧

| コマンド | 内容 |
|---|---|
| `check` | 環境とログイン状態を確認します（Web UI の「状態・ログイン」タブと同じ内容） |
| `login` | ログインの手順を表示します |
| `init` | `config.json` を作成します |
| `serve` | Web UI を起動します |
| `list` | 購入済みの作品を一覧表示します |
| `download` | 作品をダウンロードして展開します |
| `adopt` | 自分で展開したディレクトリを、ツールの管理下に取り込みます |
| `steam` | 導入済みのゲームを Steam に登録・解除します |

どのコマンドにも付けられるオプション:

| オプション | 内容 |
|---|---|
| `--config <パス>` | 設定ファイルの場所を指定します |
| `-y`、`--yes` | プロジェクトの外に書き込むときの確認を省略します |
| `--version` | バージョンを表示します |

```bash
python3 -m dlsite_deck check
```

`serve` には次のオプションがあります。

| オプション | 内容 |
|---|---|
| `--host` | 待ち受けるアドレス（既定は `127.0.0.1`）。他の端末から接続できるアドレスにするのは危険です（[使い方 — 接続とポート](usage.md#接続とポート)） |
| `--port` | 待ち受けるポート（既定は `8765`） |
| `--no-browser` | 起動時にブラウザを開きません |

`list` はカテゴリで絞り込めます。

```bash
python3 -m dlsite_deck list --category manga
```

指定できるカテゴリは `game`・`manga`・`cg`・`novel`・`voice`・`music`・`video`・`tool`・`other` です。
指定しないとゲームだけを表示し、`--all` を付けるとすべて表示します。
`--updates`（更新があるもの）、`--installed`（導入済み）、`--missing`（未取得）でも絞り込めます。

## ダウンロードと展開

作品 ID を指定してダウンロードします。

```bash
python3 -m dlsite_deck download RJ123456
```

未取得の作品をまとめてダウンロードするオプションはありません。DLsite に不正なアクセスとみなされないよう、短時間に大量のダウンロードを行わないためです。

更新がある作品をダウンロードし直します。

```bash
python3 -m dlsite_deck download --updates
```

途中で中断しても、次に実行したときに続きからダウンロードします。

| オプション | 内容 |
|---|---|
| `--dry-run` | 対象の作品を表示するだけで、実行しません |
| `--no-extract` | ダウンロードだけ行い、展開しません |
| `--keep-archives` | 展開後もアーカイブを残します（設定の `delete_archives` より優先します） |
| `--force` | 導入済みの作品も取得し直します |
| `--install-dir <パス>` | 展開先を指定します。設定したインストール先のどれかを指定してください |

## 自分で展開したゲームを取り込む

このツールを使う前に自分で展開したゲームを、ダウンロードし直さずにツールの管理下へ取り込めます。
ディレクトリと作品 ID の対応表を渡すと、`state.json` に記録します。ファイルには一切触れません。

```bash
python3 -m dlsite_deck adopt mapping.json --dry-run
```

対応表は次の形式で書きます。

```json
[{"directory": "/run/media/deck/SD/extgames/some-game", "work_id": "RJ123456"}]
```

対応表は手で書くか、自分で調べるスクリプトを用意してください。
作者が移行に使ったスクリプトは、作者の環境でしか動かないため公開していません。そのスクリプトでは、ディレクトリ内に残っている作品 ID、Steam に登録したタイトル、ディレクトリ名のローマ字を突き合わせて候補を出していました。

> [!CAUTION]
> ディレクトリ内の readme には、他の作品の宣伝として作品 ID が書かれていることがあります。
> 作品 ID だけで判断せず、名前やサイズも突き合わせて確認してください。
> 実際に、3.4 GiB のゲームが、readme に宣伝として書かれた ID のせいで 0.2 GiB の別の作品だと誤って判定されたことがあります。

## Steam への登録

Steam を終了してから実行してください。Steam の起動中に `shortcuts.vdf` を書き換えても、Steam の終了時に元に戻ってしまいます。
Steam が起動している場合は、処理を中止します（Linux と Windows のどちらでも判定します）。

実行ファイルと登録名を選びながら登録します。

```bash
python3 -m dlsite_deck steam RJ123456 --choose
```

実行ファイルと登録名を指定して登録します。

```bash
python3 -m dlsite_deck steam RJ123456 --exe "/path/to/Game.exe" --title "好きな名前"
```

導入済みのゲームを、すべて既定の設定で登録します。

```bash
python3 -m dlsite_deck steam
```

登録を解除します。

```bash
python3 -m dlsite_deck steam RJ123456 --remove
```

その他のオプション:

| オプション | 内容 |
|---|---|
| `--dry-run` | 対象を表示するだけで、実行しません |
| `--no-images` | 表紙や背景の画像を設定しません |
| `--images-only` | `shortcuts.vdf` は変更せず、登録済みのゲームに画像だけを設定します。Steam 側で名前を変えたゲームに使います |

登録を解除すると、`shortcuts.vdf` の登録に加えて、このツールが置いた表紙・背景・ロゴも削除します。
Steam のライブラリ画面から直接削除した場合は画像が残るので、画像も片付けたい場合はこのツールから解除してください。

`shortcuts.vdf` を書き換える前に、`shortcuts.vdf.bak-<日時>` という名前で控えを作ります。
同じ名前の登録がすでにある場合は、ゲームの識別と起動に関わる項目だけを更新します。起動オプション、アイコン、並び替え用の名前など、Steam で設定した内容は変更しません。

Steam のデータの場所（`userdata`）は自動で探します（Windows ではレジストリも確認します）。
見つからない場合は、`config.json` の `steam_userdata_dir` で指定してください。

## Proton の自動割り当て

DLsite のゲームは Windows 向けなので、Steam に登録するときに互換ツール（Proton）を自動で割り当てます。
既定では Proton Experimental を割り当てます。設定画面の「登録時に割り当てる Proton」で、インストール済みの Proton から選べます。公式の Proton と、`compatibilitytools.d` に置いた GE-Proton などの両方が選択肢に出ます。

すでに Proton が割り当てられているゲームは変更しません。ゲームごとに使い分けている設定を上書きしないためです。

割り当ては `<Steam のディレクトリ>/config/config.vdf` の `CompatToolMapping` に記録されます。
このファイルには Steam の設定が数多く入っているので、該当する部分だけを書き換え、書き換える前に控えを作ります。

> [!NOTE]
> 設定に書く名前は、ディレクトリ名とは綴りが異なります。
> `Proton 8.0` は `proton_8`、`Proton 5.13` は `proton_513`、`Proton - Experimental` は `proton_experimental` です。
> `compatibilitytools.d` に置いたものは、ディレクトリ名がそのまま名前になります。

## Proton 設定タブ

Web UI の「Proton 設定」タブには、Steam に登録したゲームの一覧と、それぞれに割り当てられている Proton が表示されます。
行ごとに選び直すと、その場で変更されます。

- タイトルや作品 ID、割り当て済み／未設定で絞り込めます。
- タイトル順と Proton 順で並べ替えられます（昇順・降順）。Proton 順では、同じ Proton の中をタイトル順に並べ、未設定のゲームは最後に置きます。

Steam の設定画面から変更するのと同じ効果があります。書き込む場所も形式も、Steam が書くものと同じです。

> [!IMPORTANT]
> Steam を終了してから操作してください。
> Steam は起動中に `config.vdf` の内容を手元に持っていて、終了するときに書き戻します。起動中に書き換えても元に戻ってしまうため、起動中は変更できないようにしています。

一覧にない Proton が割り当てられている場合（`compatibilitytools.d` から削除した GE-Proton など）は、その名前を赤字で表示し、選択肢にも残します。気付かないうちに別のバージョンへ変えてしまわないようにするためです。

「未起動」と表示されているゲームは、まだ Proton の環境（プレフィックス）が作られていません。Steam から一度起動すると作られます。

## 起動オプション（日本語の文字化け対策）

SteamOS には日本語のロケール（`ja_JP.UTF-8`）が入っていません。そのため、日本語のゲームでは画面の表示やファイル名が文字化けすることがあります。
Steam の起動オプションでロケールを指定すると直ります。

`config.json` の `steam_launch_options` に書いておくと、Web UI から新しく登録するゲームに付きます。登録画面には付く内容が表示されますが、画面からは変更できません。起動オプションには任意のコマンドを書けるため、他のプログラムがツールを使って書き込めないようにしています。

ロケールの用意の仕方は環境によって異なるので、既定では空にしています。
よく使われるのは、ロケールを自分で用意して読み込ませる方法です。

```
LANG=ja_JP.UTF-8 ~/locales/run.sh  %command%
```

`%command%` は、Steam が実際の起動コマンドに置き換えます。

すでに Steam に登録してあるゲームを登録し直す場合は、Steam で設定されている起動オプションをそのまま使います（名前を変えて登録し直す場合も引き継ぎます）。Steam で設定した内容が知らないうちに消えることはありません。
登録済みのゲームの起動オプションを変えたいときは、Steam でゲームのプロパティを開いて変更してください。

## ライブラリの表紙と背景

Steam に登録するとき、DLsite のストアページの 1 枚目の画像を、ライブラリの画像として設定します。
Steam は非 Steam ゲームの画像を `userdata/<ID>/config/grid/` に AppID 名のファイルとして保存するので、そこに画像を置きます。exe と同じディレクトリに画像を置いて読み込ませる仕組みは、Steam にはありません。

| ファイル名 | 用途 | Steam が想定する大きさ |
|---|---|---|
| `<AppID>p.jpg` | ライブラリの表紙（縦長） | 600×900 |
| `<AppID>_hero.jpg` | 背景 | 1920×620 |
| `<AppID>.jpg` | 横長の画像 | 460×215 |
| `<AppID>_logo.png` | ロゴ（背景の上に表示） | 自由・透過 PNG |

`<AppID>` は、`shortcuts.vdf` の `appid` を符号なしの数値で表したものです。

DLsite の画像は 560×420（縦横比 4:3）で、上のどの大きさとも縦横比が合いません。

### 縦長の表紙にタイトルを入れる

Steam で販売されているゲームは表紙にタイトルが入っていますが、DLsite の画像には入っていません。
そのままではライブラリの一覧でどれがどのゲームか分からないので、縦長の表紙だけは次の手順で作り直します（設定の `steam_cover_title`）。

1. 作品の画像の中央を、縦横比 2:3 で切り出します（560×420 の画像から、中央の 280×420 を使います）。
2. 600×900 に拡大します。
3. 下の部分に白い半透明の帯を敷き、その上に白い文字と太い黒の縁取りでタイトルを描きます。
4. 文字の大きさは、1 行に全角で 10 文字入るように決め、そこで折り返します。

タイトルが長くて行数が多くなるときは、表紙が文字で埋まらないように自動で文字を小さくします。
半角文字は全角の半分として数えるので、英語のタイトルなら 1 行に 20 文字入ります。

作り直すのは縦長の表紙だけです。横長の画像（460×215）と背景（1920×620）は縦横比が違うので、元の画像をそのまま使います。

### ロゴ

設定の `steam_logo_source` で、次の 3 つから選べます。

| 値 | 内容 |
|---|---|
| `title`（既定） | タイトルだけを描いた透過 PNG です。折り返さずに 1 行で描き、文字の見た目は表紙と同じです |
| `exe` | exe に含まれるアイコンのうち、いちばん大きいものを PNG にして使います。アイコンがない exe の場合は設定しません |
| `none` | ロゴを設定しません |

`exe` の場合、依存するライブラリを増やさないよう、exe の解析と PNG の書き出しはツール自身で行っています。PNG 形式のアイコンと、32・24・8・4・1 ビットの DIB 形式のアイコンに対応しています。

### ストア画像の保存

ダウンロードしたストア画像は、作品のディレクトリに `.dlsite-store-image.jpg`（PNG の場合は `.png`）という名前で保存します。
表紙を作り直すたびに DLsite から取得し直すのは無駄ですし、ログインが切れていると取得できないためです。

- 表紙の作り直しは、通常は通信せずに行えます。作者の環境では、3 件の作り直しが 1.1 秒で終わりました。
- ファイル名が `.` で始まるので、通常は表示されません。作品を削除すると、ディレクトリごと削除されます。
- 保存した画像が壊れている場合や形式が違う場合は、DLsite から取得し直します。

### カバーを作り直す

設定を変えたあと、Steam に登録し直さずに画像へ反映させる操作です。
Web UI の設定タブにある「カバーを作り直す」ボタンで実行します。

登録済みのすべてのゲームについて、表紙・背景・ロゴを今の設定に合わせます。新しく作るだけでなく、使わなくなった画像は削除します。

| 変更した設定 | 起こること |
|---|---|
| `steam_cover_title` を `false` にした | タイトル入りの表紙を削除し、元の画像を置き直します |
| `steam_logo_source` を `none` にした | 置いてあるロゴを削除します |
| `steam_grid_slots` から項目を外した | その種類の画像を削除します |
| `steam_grid_images` を `false` にした | 登録済みのゲームの画像をすべて削除します |

設定を戻してからもう一度実行すると、元の状態に戻ります。
「別環境と重複」と表示されているゲームは変更しません（名前で照合するため、別の環境の登録を書き換えてしまうからです）。

Steam は起動中に読み込んだ画像を使い続けるので、表示に反映されるのは Steam を再起動したあとです。
画像ファイルを書き換えること自体は Steam の起動中でも問題ないので、この操作は Steam の起動中でも行えます。

コマンドラインでは `--images-only` で同じことができます。

```bash
python3 -m dlsite_deck steam --images-only
```

### 描画に使うもの

タイトルの描画には `rsvg-convert` を使います。SteamOS に最初から入っているコマンドで、フォント（Noto Sans CJK JP）の選択や日本語の文字の描画を任せています。
Python の標準ライブラリだけではフォントから文字を描けないため、この部分だけは外部のコマンドを使っています。

`rsvg-convert` がない環境では、タイトルを入れずに元の画像をそのまま使います。Steam への登録自体は通常どおり行われます。

### 既定値は環境によって決まる

`steam_cover_title` の既定値は、その環境でタイトルを描けるかどうかによって決まります。

| 環境 | 既定値 |
|---|---|
| `rsvg-convert` と日本語フォントの両方がある | オン |
| どちらかがない | オフ |

描けない環境でオンにしても、タイトルが「□」（いわゆる豆腐）の並んだ表紙ができるだけだからです。
`config.json` に値を書いている場合は、その値が優先されます。

日本語フォントがあるかどうかは、`fc-list :lang=ja` で調べます。
実際に文字を描いて比べる方法は使えません。フォントにない文字は「□」になりますが、最近の「□」は枠の中に文字コードを表示するので、文字ごとに違う絵になり、比べても見分けられないためです。
`fc-list` がない環境では判断できないので、描けるものとして扱います。

オフからオンに切り替えたとき、描けない環境であれば警告を表示します。設定画面ではチェックを入れたときに理由を表示し、保存するときにも表示します。
保存はそのまま行えます（他の環境へ設定を持っていけば使えるためです）。

### 画像を使わない

表紙の加工が不要な場合は、`steam_cover_title` を `false` にします。切り出しもタイトルの描画も行わず、元の画像をそのまま使います。
`steam_grid_slots` から `"cover"` を外したり、`steam_grid_images` を `false` にして SteamGridDB などの画像を手で設定したりすることもできます。

特定のゲームだけ画像を設定しない場合は、登録時に `--no-images` を付けます。

```bash
python3 -m dlsite_deck steam RJ123456 --no-images
```
