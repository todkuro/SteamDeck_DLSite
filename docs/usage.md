# 使い方

ふだんの操作はすべて Web UI で行えます。端末を使うのは起動するときだけで、SteamDeck ではそれもダブルクリックで済ませられます。

## 起動と終了

```bash
python3 -m dlsite_deck serve
```

起動するとブラウザが開きます。

SteamDeck では、同梱の `dlsite-deck.sh` に実行権限を付けておくと、デスクトップモードでダブルクリックするだけで起動できます。

```bash
chmod +x ~/Applications/dlsite_deck/dlsite-deck.sh
```

終了するときは、画面右上の「終了」を押してください。端末から起動した場合は Ctrl-C でも終了できます。
ダウンロード中の作品や順番待ちの作品があるときは、その件数を表示して確認します。終了すると処理が中断され、途中までのファイルが残るためです。

### 使っていないときは自動で終了します

デスクトップモードでは、ブラウザのタブを閉じてもツールは裏で動き続けます。そのままにしないよう、**画面を閉じてから 30 分たつと、ツールは自動で終了します。**

- 画面を開いている間は、画面が 1 分ごとにツールへ合図を送るので終了しません。
- ダウンロード、展開、順番待ち、表紙の作り直しの途中は終了しません。終わってから数え始めます。
- 端末がスリープしていた時間は数えません。
- 終了したあとに画面を操作すると、「ツールは終了しています」と表示されます。使うときは、もう一度起動してください。

終了するまでの時間は、設定の「使っていないときに自動で終了する」で変えられます（10 分・30 分・1 時間・2 時間、または終了しない）。変更は次の起動から反映されます。

## アプリケーションメニューに登録する（デスクトップモード）

デスクトップモードでは、画面左下の「アプリケーションランチャー」が Windows のスタートメニューにあたります。
ここにツールを登録するには、`.desktop` ファイルをホームディレクトリの中に置きます。`sudo` は不要で、SteamOS を更新しても消えません。

| 置き場所 | 対象 |
|---|---|
| `~/.local/share/applications/` | 自分だけ。**こちらを使います** |
| `/usr/share/applications/` | すべてのユーザー。システム領域なので使いません |

同梱の `dlsite-deck.desktop` はパスが仮のものになっているので、書き換えてからコピーします。
`~/Applications/dlsite_deck` に置いた場合は、次の 2 つのコマンドを実行します。

```bash
chmod +x ~/Applications/dlsite_deck/dlsite-deck.sh
```

```bash
mkdir -p ~/.local/share/applications && sed -e "s|/path/to/dlsite_deck/dlsite-deck.sh|$HOME/Applications/dlsite_deck/dlsite-deck.sh|" -e "s|^Path=/path/to/dlsite_deck|Path=$HOME/Applications/dlsite_deck|" ~/Applications/dlsite_deck/dlsite-deck.desktop > ~/.local/share/applications/dlsite-deck.desktop
```

メニューの「ゲーム」と「ユーティリティ」に **DLsite for SteamDeck** が表示されます。
すぐに表示されない場合は、次のコマンドでメニューを更新してください。

```bash
kbuildsycoca6 --noincremental
```

表示された項目を右クリックすると、タスクバーへの固定、デスクトップへの追加、お気に入りへの追加もできます。

補足:

- `.desktop` ファイルの `Exec` と `Path` には絶対パスを書く必要があります。`~` は使えないため、上のコマンドで `$HOME` を実際のパスに置き換えています。
- 起動すると、ログを表示する端末のウィンドウも一緒に開きます（`Terminal=true`）。うまく起動しなかったときに原因を確認できるようにするためです。このウィンドウを閉じるとツールも終了します。
  ウィンドウを出したくない場合は `Terminal=false` に変更できますが、起動に失敗しても何も表示されなくなります。
- 初回だけは、先に端末から一度起動してください。展開先がプロジェクトの外にある場合、書き込みの確認が表示されるためです（理由は次の節を参照してください）。

```bash
cd ~/Applications/dlsite_deck && python3 -m dlsite_deck -y serve --no-browser
```

コマンドを使わずに登録したい場合は、ランチャーを右クリックして「アプリケーションの編集」を選ぶと、メニューエディタから同じことができます。ただし、各項目を手で入力する必要があります。

> [!NOTE]
> メニューに登録しても、使えるのはデスクトップモードだけです。ゲームモードで使うには、次の節の手順が必要です。

## ゲームモードから使う

ツール自体を Steam に「非 Steam ゲーム」として登録すると、ゲームモードからも起動できます。

### 事前に一度だけ承認しておく

展開先がプロジェクトの外にある場合、初めて起動したときに書き込みの確認が表示されます。
Steam やメニューから起動したときは端末がないので、この確認に答えられません。先に端末から次のコマンドを実行して、承認を済ませておいてください。

```bash
python3 -m dlsite_deck -y serve --no-browser
```

承認した内容は `config.json` の `acknowledged_paths` に記録され、次からは確認されません。

### Steam に登録する

1. デスクトップモードで Steam を開き、左下の「ゲームを追加」→「非 Steam ゲームを追加」を選びます。
2. 「参照」を押し、ファイルの種類を「すべてのファイル」に変えて `dlsite-deck.sh` を選びます。
3. 追加したゲームのプロパティを開き、「互換性」で Proton を**有効にしない**でください。Linux のシェルスクリプトなので、Proton を通すと起動しません。

ゲームモードで起動すると、Web UI とブラウザ（Flatpak 版の Firefox）が開きます。終了はゲームモードの「ゲームを終了」から行います。

> [!TIP]
> ゲームモードではタッチとコントローラでしか操作できないので、細かい設定はデスクトップモードで行うほうが快適です。

コントローラの設定はこのツールからは変更できません。ゲームモードで直接設定してください。
理由は [既知の制限](limitations.md#コントローラ設定を扱えない理由) に書いています。

## 画面の説明

### ライブラリ

購入済みの作品が一覧で表示されます。

**表示の切り替えと絞り込み**

- カテゴリで表示する作品の種類を切り替えます。最初はゲームだけが表示されます。マンガ、CG、ボイス、音楽、動画も選べます。
- 状態（未取得 / 導入済み / 更新あり / 更新不明 / Steam未登録 / 別環境と重複）や、タイトル・作品 ID で絞り込めます。
- 「更新不明」は、更新があるかどうかを判定できない作品です。DLsite が更新日を返さない作品が多く（作者の環境では約 4 割）、「導入済み」とだけ表示すると「更新がない」のか「分からない」のか区別できないため、分けて表示しています。

**Steam への登録状態**

- ダウンロードしただけで Steam に登録していないゲームには、「導入済み」と並んで「Steam未登録」と表示されます。見出しにも未登録の件数が出るので、登録し忘れに気付けます。
- 登録状態は、ツールの記録ではなく Steam の `shortcuts.vdf` を直接読んで判定します。Steam 側で登録を削除した場合も正しく反映されます。Steam が見つからない環境では「登録状態不明」と表示します。
- Steam は、別の端末で登録した非 Steam ゲームの情報を表示することがあります。exe のパスの形式から別の OS のものだと確実に判断できた場合は、この端末の登録として数えません。
  同じ名前の登録が別の環境にある作品は「別環境と重複」と表示し、登録と解除のボタンを押せなくします。Steam の登録は名前で照合するため、そのまま操作すると別の環境の登録を書き換えてしまうからです。
  パスの形式から判断できない場合は、この端末の登録として扱います。

**並び順**

最初は「次にやること」の順に並びます。同じ状態の中ではタイトル順です。

```
Steam未登録 → 更新あり → 未取得 → 登録済み・更新不明 → 記録のみ → 別環境と重複
```

「別環境と重複」はこの端末からは操作できないので、最後に置いています。

並び順は、購入日・タイトル・更新日・状態・サイズから選べます（昇順・降順）。
タイトル以外で並べたときは、同じ値の作品をタイトル順に並べます。値がない作品（更新日を返さない作品など）は、昇順・降順にかかわらず最後に置きます。

「状態」で並べたときは、手を動かす必要がある順になります。

```
更新あり → 別環境と重複 → Steam未登録 → 登録済み・更新不明 → 記録のみ → 未取得
```

「更新不明」は判定できない作品に常に付く表示で、対処のしようがないため、「登録済み」と同じ扱いにしています。

**ダウンロード**

- インストール先を一覧から選びます。設定で決めた既定のインストール先が、最初から選ばれています。
- 作品ごとに「取得」を押してダウンロードします。DLsite に不正なアクセスとみなされないよう、表示中の作品をまとめて取得するボタンは置いていません。
- ダウンロードは一度に 1 件ずつ、押した順に行います。続けて押した分は順番待ちになり、行に「順番待ち N」と表示されます。始まる前であれば「取り消し」で取りやめられます。
- 進行状況は画面上部に固定表示されるので、一覧をスクロールしても確認できます。ダウンロード中の行では、ボタンが進行状況の表示に変わり、「中止」を押せます。
- 中止すると、ダウンロード済みのファイルは削除されます。展開は途中で安全に止められないため、展開中は中止できません。
- 展開が終わるとアーカイブは自動で削除され、行の表示がその場で切り替わります（「取得」→「Steam登録」など）。順番待ちが残っていても、終わった作品から順に切り替わります。

**Steam への登録**

- 実行ファイルが複数ある作品では、どれを登録するか選べます。候補にはサブディレクトリの中の exe も含みます（`InstallSet/InstallData/<本体>.exe` のような構成の作品があるためです）。
- アンインストーラや設定ツールらしいものには「ゲーム本体でない可能性」と表示して、下の方に並べます。候補から外すことはしません。
- 登録名の初期値は作品のタイトル（DLsite のタイトル、自由登録ではゲーム名）で、その場で変更できます。
- 起動オプションは表示だけで、画面からは変更できません。新しく登録するゲームには `config.json` の値が付き、登録済みのゲームは Steam での設定をそのまま使います（[起動オプション](cli.md#起動オプション日本語の文字化け対策)）。
- 登録の解除もここから行います。

**実行（設定用のアプリなど）**

設定用のアプリ（`Config.exe` など）がゲーム本体と別になっている作品があります。Steam には本体しか登録しないので、それ以外の exe は「実行」から動かします。

- ゲームの中の exe が並ぶので、選んで「実行」を押します。Steam に登録している exe には「Steam に登録中」と表示されます。アンインストーラーは表示しません。
- そのゲームの Proton 環境（同じ AppID のプレフィックス）で、exe のあるディレクトリを作業ディレクトリにして実行します。設定アプリで変えた内容は、ゲーム本体にもそのまま効きます。
- 既定では、そのゲームに Steam で設定してある起動オプション（`LANG=ja_JP.UTF-8 … %command%` など）を付けて実行するので、ゲームと同じ言語設定で動きます。チェックボックスで外せます。引数も指定できます（空欄なら付けません）。
- Steam に登録していないゲームでは使用できません。Proton の環境は Steam の登録に結び付いているためです。
- パッチと違い、「実行済み」の記録は残しません。

**「記録のみ」の作品**

ツールの記録には残っているのに、ディレクトリが見つからない状態です。ツールの外でディレクトリを消した場合のほか、インストール先の SD カードが挿さっていない場合にも起こります。SD カードの場合はそこに置いたすべての作品がこの状態になるので、取得し直す前にカードを確認してください。

設定したインストール先やキャッシュの置き場が見つからないときは、画面上部に警告が出ます。その場所が `/run/media` の下などの取り外せる媒体で、そこに「記録のみ」の作品がある場合は、SD カードが外れている可能性があることも表示します。

**削除**

展開したファイルとダウンロードしたアーカイブを消し、ツールの記録からも外します。

- Steam に登録している作品は削除できません。削除すると、起動できないショートカットだけが Steam に残ってしまうためです。先に「解除」してください。
- 削除する前に、解放される容量が表示されます。その作品を DLC として他の作品に重ねている場合は、その作品名も表示されます（重ねたファイルは相手の作品に残ります）。
- DLC を重ねたときに退避したファイルも、一緒に削除されます。
- インストール先の外にあるディレクトリは、設定を書き換えても削除しません。

### 自由登録

DLsite 以外のゲームを、アーカイブかディレクトリから取り込んで、ライブラリの作品と同じように扱えます。
DLsite には問い合わせないので、ログインしていなくても使えます。

**取り込み元を用意する**

取り込むアーカイブやディレクトリは、取り込み元に置きます。既定はツールのディレクトリの中の `imports/` です。
取り込み元は「設定」タブの「自由登録の取り込み元」で変更できます（1 行に 1 つ。`~/Downloads` など、既にあるディレクトリを指定します）。
新規登録で選べるのは、取り込み元の中だけです。
隠しディレクトリ（`~/.mozilla` や `~/.var` のように `.` で始まるもの）とその中は、他のアプリのデータが置かれる場所なので指定できません（[既知の制限 — セキュリティ](limitations.md#セキュリティ)）。

**新規登録**

「新規登録」を押して、次の項目を入力します。「登録」を押すと、アーカイブの展開（ディレクトリの場合はコピー）が始まり、終わると一覧に載ります。進み具合は画面上部に表示されます。

| 項目 | 内容 |
|---|---|
| ゲーム名 | 一覧と Steam の登録名の初期値になります。取り込むものを先に選ぶと、その名前が入ります |
| ディレクトリ名 | 「ゲーム名を使用」「ゲーム名をローマ字にする」「入力する」から選びます。`/ \ : * ? " < > \|` は使えません。同じ名前のディレクトリが既にあるときは登録できません |
| アーカイブ・ディレクトリの場所 | 「選ぶ」で取り込み元の中をたどって選びます。ディレクトリを選んだ場合も、中身をインストール先へコピーします（元のディレクトリはそのまま残ります） |
| インストール先 | 既定はライブラリと同じです。設定した他のインストール先も選べます |
| 使う Proton | Steam に登録するときに割り当てる Proton です。初期値はライブラリのゲームと同じ（設定の「登録時に割り当てる Proton」）です |

- 取り込めるアーカイブは ZIP・RAR・7z です。分割されたもの（`.001`、`.part1.rar`、`.zip` と `.z01` など）は、先頭のファイルを選んでください。ZIP 以外は、展開に 7z などのコマンドを使います（[インストール](install.md)）。
- 単一のディレクトリの引き上げや、名前からのバージョン番号の除去は、ライブラリの作品と同じ設定に従います。
- 作品 ID は `LOCAL-0001` のように振られます。

**登録したあとの操作**

ライブラリと同じく、Steam への登録と解除、実行、DLC、パッチ、削除ができます。自由登録だけの操作が 2 つあります。

| 操作 | 内容 |
|---|---|
| 画像 | 表紙・背景に使う画像（PNG か JPEG）を、取り込み元の中から選びます。Steam に登録済みなら、その場でライブラリの画像も作り直します（Steam を起動し直すと反映されます） |
| アーカイブ削除 | 取り込み元に残っているアーカイブを削除します。分割されたものは、続きのファイルもまとめて削除します。取り込み元の外にあるものは削除しません |

削除すると、取り込んだファイルが消えます。取り込み直すには、元のアーカイブかディレクトリが必要です。

### Proton 設定

Steam に登録したゲームの一覧と、それぞれに割り当てられている Proton が表示されます。行ごとに選び直すと、その場で変更されます。Steam の設定画面から変更するのと同じ効果があります。

Steam を終了してから操作してください（Steam の起動中は変更できません）。
詳しくは [コマンドライン — Proton 設定タブ](cli.md#proton-設定タブ) をご覧ください。

### 状態・ログイン

次の項目をまとめて表示します。

- Cookie を読み取れているか、DLsite に接続できるか
- 分割 RAR を展開するコマンド、pykakasi の有無
- Steam が起動しているか、Steam のデータの場所（`userdata`）
- インストール先の空き容量

ログインが切れているときは、この画面にログインの手順が表示されます。

### 設定

`config.json` の内容を画面から編集して保存できます。保存するときに値が正しいかを確認します。

**場所やプログラムを指す設定は、画面からは変更できません。** キャッシュの置き場、状態ファイル、Cookie ファイル、Steam の userdata、Steam の実行ファイル、既定の起動オプション、展開ツールを探す場所がこれに当たります。画面には現在の値だけを表示するので、変更するときは `config.json` を直接編集してください。
これらを変えられると、他のプログラムがツールを使って任意のプログラムを実行したり、ゲームを別の場所にダウンロードさせたりできてしまうためです（[既知の制限 — セキュリティ](limitations.md#セキュリティ)）。

- **保存ボタン**は、画面をスクロールしても見出しのすぐ下に表示されたままになります。設定したあと、保存せずに他のタブへ移ってしまうのを防ぐためです。
- 変更を保存していないときは、保存ボタンが「保存（未保存の変更あり）」に変わります。その状態で他のタブへ移ろうとすると、確認が表示されます。変更を破棄して移ることもできます。タブを閉じたり再読み込みしたりするときは、ブラウザの確認が表示されます。
- **インストール先**は複数登録できます。「インストール先の一覧」に 1 行に 1 つずつ書き、「既定のインストール先」でどれを最初に選ぶかを決めます。変更はライブラリ画面にすぐ反映されます。ゲームごとに自由な場所を選ぶ機能はなく、ここで登録した場所から選びます。
- 画面からインストール先に追加できるのは、**承認済みの場所だけ**です（一覧の下に表示されます）。承認済みの場所とは、端末から起動したときに承認した場所と、プロジェクトの `games/` のことです。
  新しい場所（別の SD カードなど）を使うときは、`config.json` の `install_dirs` に書いてから、端末でツールを一度起動して承認してください。次からは画面で追加・削除できます。
- **「カバーを作り直す」**ボタンを押すと、登録済みのゲームの画像を今の設定に合わせて作り直します。「縦長カバーにタイトルを載せる」などを切り替えて保存したあとに使います。登録し直す必要はありません。
  進み具合はボタンの横に表示されます。元の画像は作品ディレクトリに残しているので、通常はダウンロードし直しません。Steam を再起動すると表示に反映されます。
  詳しくは [コマンドライン — カバーを作り直す](cli.md#カバーを作り直す) をご覧ください。

## Steam が起動しているとき

Steam は起動中、`config.vdf` と `shortcuts.vdf` の内容を手元に持っていて、終了するときにファイルへ書き戻します。
そのため、Steam の起動中にこれらのファイルを書き換えても、終了時に元に戻ってしまいます。
これを防ぐため、Steam の起動中は次の操作をできなくしています。

- Steam への登録と解除
- Proton 設定タブでの変更

このとき、画面上部に帯が表示され、次の 2 つのボタンが並びます。

- **「Steam を終了する」**：Steam に終了を指示し、実際に終了するまで待ちます。`steam -shutdown` を使うので、Steam は自分で後片付けをしてから終了します（`pkill` などで強制終了すると、`shortcuts.vdf` を書き戻す前に止まってしまうことがあります）。起動中のゲームがあれば、先に終了しておいてください。
- **「Steam を終了しました」**：Steam を自分で終了したあとに押します。まだ動いている場合はそのことを表示し、終了していれば帯が消えて操作できるようになります。

一覧を開いたまま Steam を起動することもあるので、ボタンを押したときにも Steam が起動していないかを確認します。起動していれば処理を中止し、起動中の表示に切り替えます。
なお、ダウンロード、展開、削除、DLC の重ね合わせは Steam に関係しないので、Steam の起動中でも行えます。

Steam の実行ファイルの場所は、`config.json` の `steam_executable` で変更できます。既定は SteamDeck の `/usr/bin/steam` です。そこにない場合は PATH や Steam のディレクトリからも探すので、通常は変更しなくてかまいません。

### ゲームモードでは Steam を終了できません

ゲームモードでは Steam そのものが画面全体を管理していて、このツールも Steam から起動されています。Steam を終了するとツールも一緒に終了してしまうので、ゲームモードでは上の操作を行えません。
そのため、ゲームモードでは 2 つのボタンは表示せず、デスクトップモードに切り替えて操作するよう案内します。

どちらのモードかは、動いているプロセスから判定します（ゲームモードでは `gamescope`、デスクトップモードでは KDE Plasma が動いています）。

## ログイン

ログインが必要なのは、最初に使うときと、ログインが切れたときだけです。「状態・ログイン」タブにも同じ手順が表示されます。

1. Firefox で https://www.dlsite.com/ にいつもどおりログインします（2 段階認証も含めて）。
2. 続けて https://play.dlsite.com/ を一度開きます。DLsite Play 側のログインは、このページを開いたときに行われます。
3. Firefox は開いたままでかまいません。Web UI に戻り、「再確認」を押します。

DLsite Play 側のログインはすぐに切れますが、ツールが使うたびに自動でつなぎ直すので、ブラウザでログインし直す必要は基本的にありません。
つなぎ直すときも、ID・パスワード・2FA コードは使いません。
「状態・ログイン」タブでは、つなぎ直したかどうかを区別せず「有効」と表示します（`check` では「Play 側セッションを再取得しました」と表示します）。

このツールは Firefox の Cookie を読み取るだけで、ID・パスワード・2FA コードを受け取ったり保存したりすることはありません。

## 接続とポート

Web UI は、既定では同じ端末（`127.0.0.1`）からしか接続できません。ライブラリの内容が外部に出ることはありません。

同じ端末で動く他の Web サイトやプログラムからも、操作されないようにしています。ツールは起動するたびに合言葉を作り、ブラウザで開く URL の末尾に付けます（`http://127.0.0.1:8765/#t=…`）。この合言葉が付いた画面からの操作だけを受け付けます。

そのため、次の点に気を付けてください。

- **別のウィンドウで開くときは、`#t=…` まで含めた URL を使ってください。** 起動した端末に「Web UI を起動しました:」として表示されます。`http://127.0.0.1:8765/` だけを開くと、開き直し方の案内が表示されます。
- 同じ起動のあいだは、F5 で再読み込みしてもそのまま使えます。
- **ツールを起動し直すと合言葉が変わります。** 前に開いたタブは閉じて、新しく開いたタブを使ってください。前のタブからは操作できません。

> [!WARNING]
> `--host` オプションで、他の端末からの接続を許可しないでください。
> 他の端末から操作するにも起動ごとの合言葉が必要ですが、通信は暗号化されません（HTTP）。同じネットワークで通信を盗み見られると、合言葉と購入履歴を読まれ、ダウンロードや削除などの操作をされてしまいます。
> 他の端末から接続できるアドレスを指定した場合は、起動時に警告を表示します。

起動するときに、ポートがすでに使われていないかを確認します。

| 状況 | 動作 |
|---|---|
| このツールがすでに同じポートで動いている | すでに動いていることを表示して終了します。画面は、動いている方のツールの端末に表示された URL（`#t=…` を含む）で開いてください |
| 別のプログラムが同じポートを使っている | 別のポートを指定するよう表示して終了します |
| このツールが別のポートで動いている | `state.json` が壊れるおそれがあることを警告して、起動を続けます |

終了する場合、終了コードは 1 です。
